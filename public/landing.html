Scoped permissions

Each agent receives its own key limited to the exact actions you allow. Read, write, or specific resources. Nothing more.

Credentials stay server-side

The agent never sees your AWS keys, GitHub token, or Slack bot token. The gate holds them and proxies every call.

Instant kill switch

Revoke any agent in one click. In-flight requests are aborted. The agent stops immediately, even if it is mid-task.
